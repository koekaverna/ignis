    ADR index¶

    Every architectural decision, rejection and deferral, in one place (owner ADR sweep, 2026-09-17). Status vocabulary: accepted | proposed | deferred (with trigger) | rejected | superseded-by. Only the main agent sets "accepted". Numbers in an ADR cite a V-n or say "unmeasured".

    # title status decision in one line
    0001 Embedding via raw bindgen, reactor in Rust, scheduler in PHP userland accepted (V-1) bindgen over the embed headers; the reactor is the only bridge; the scheduler is php/packages/runtime/src/ignis.php
    0002 Value-based HTTP request boundary and a userland fiber pool accepted (V-4) + addendum: the network path never waits for PHP requests cross as plain data; parked fibers are reused; hyper never runs on a PHP thread
    0003 Reactor/scheduler behind a trait with two backends accepted (V-7) mainline PHP is the production backend; the true-async fork stays a second target
    0004 N PHP worker OS threads, one reactor each accepted (V-9) threads = cores, each with its own engine context and reactor
    0005 RSS is the E3 metric, measured from inside the process accepted (V-10) RSS from /proc/self/status, PHP heap from memory_get_usage()
    0006 Superglobals swapped per fiber by a switch observer accepted (V-11) + addendum: fiber-scoped services model scope is bound to dispatch, not the Fiber object; children inherit by reference; the static-slot list is the extension point
    0007 tcp:// transport replaced at MINIT; stream ops park from C superseded by 0037 (V-49) — the factory is deleted, the syscall parks instead unmodified file_get_contents/fsockopen park; hook-off control for every claim
    0008 Revolt driver over ignis_poll accepted (V-13) AMPHP runs unchanged; fd readiness via ignis_watch
    0009 Disconnect is a cancel event; one deadline per request accepted (V-14, V-30) + addendum: the contract and its gaps cancellation is an exception in PHP and (stage 2) ECANCELED in C; spawn() detachment and immediate surfacing of unawaited failures are recorded gaps
    0010 Least-inflight dispatch accepted (V-15) one target per request, chosen by pending count; stalled threads skipped
    0011 Symfony via a symfony/runtime class accepted (V-16, V-40) ignis/runtime composer package, extra.runtime.class, entry = public/index.php
    0012 Thread death is local; a supervisor respawns; a watchdog reports stalls accepted (V-17) a fatal ends one thread, respawned without an opcache reset
    0013 Temporal sdk-core in-process, workflows as fibers accepted for the prototype (V-18, V-19) deterministic replay passes; signals/queries/cancel are E9'
    0014 gRPC on the shared hyper/h2 stack, opaque-bytes codec accepted (V-20) unary + server-streaming in PHP; the client parks the fiber
    0015 Runtime-owned PostgreSQL pool with per-fiber leases closed and removed (2026-09-18) park made the ordinary driver asynchronous (V-45/V-59), the pool moved into ignis/doctrine (V-85), and the native client measured slower than parked pdo_pgsql (V-86)
    0016 Offload pool on synchronous worker threads accepted (V-24) + addendum: default routing shrank (V-59 + addendum, 1ee99cb) scalars/arrays cross, objects/resources do not; handles pinned to a worker; callbacks on the caller. Default auto-routing is now SQLite3 alone — curl_* (328 ms parked vs 2,697 ms routed) and PDO/pgsql (303 ms parked vs 2,753 ms routed) park by default instead of routing; IGNIS_OFFLOAD_FUNCTIONS/IGNIS_OFFLOAD_CLASSES restore the old routing
    0017 ssl:///tls:// on the stream hook via rustls superseded by 0037 (V-49) rustls is gone; TLS is ext/openssl over parked syscalls, which closed A6/B7 by construction
    0018 ext/sockets parking and unix:// superseded by 0037 (V-48); kill criterion 2 had been replaced by owner decision (V-29, V-33) park then delegate; readiness is not "would succeed" (can_block)
    0019 Fiber budget: admission with a queue and a 503 past it accepted (V-37) waiting requests are data, not fibers; the RSS bound is the connection cap (ADR-0025)
    0020 Universal park: interpose the blocking libc calls behind a fiber gate accepted for the mechanism; stages 1–2 built and the stream/sockets/accept hooks deleted under ADR-0037 (V-45–V-49); flock joined the interposed set 2026-09-18 (V-81) default block, allow-list park; detector-first rollout; kill criterion: an OpenSSL/libcurl failure with a lock in the trace; seed is SEED in park.rs (16 libphp: symbols plus libcurl/libpq/libssl/libcrypto today, and it grows per cycle — do not copy it here)
    0021 I/O coverage is layered, not per-function accepted; superseded-by 0037 as to mechanisms Revolt → stream hooks → offload → universal park, with what each cannot cover
    0022 Observability contract accepted (per line built/unbuilt) warn floor, runtime-answered health, hold-time on every lease, spans per park, loop lag, ignis dump
    0023 Validation rules accepted suites gated in CI; benches local and quiet; soak = no trend past 5M; agents' numbers re-run by main; chaos mode standard
    0024 What the runtime does not promise accepted no durability across crashes, not a web server, one app per process, no NTS, no multi-tenant isolation, no sub-ms timers
    0025 Memory model under ZTS accepted memory_limit is per thread; budget + headroom shedding; the connection cap is the RSS bound
    0026 Timer contract accepted tokio's 1 ms wheel; sleep(0) inline; not for sub-millisecond scheduling
    0027 Build and distribution accepted / deferred own PHP ZTS build; the image ships; glibc static (no musl) once M5-5 shows it feasible; arm64 on demand
    0028 Laravel compatibility model accepted (implementation open) classic mode with budget.fibers = 1 now; fiber-scoped Container later; the budget-2 control must fail
    0029 Vendor state policy accepted as policy (implementation open) find (scanner, chaos, leak detector) → classify → isolate ladder; ignis audit and a compat allowlist
    0030 Preemption of CPU-bound fibers proposed watchdog escalation to an opcode-boundary suspend, opt-in per route, never default
    0031 Persistent inbound connections (WS/SSE) proposed fiber per connection, backpressure in Rust, respawn drops connections — documented
    0032 Inbound TLS and HTTP/3 deferred rustls termination first, h3 via quinn after; triggers: staging TLS, mobile clients not behind a CDN
    0033 Per-thread reactor for in-request I/O deferred one queue crossing each way is the budget; trigger: > 5 % of request time in ready/wakeup
    0034 GC and destructors proposed loop-scheduled GC; forbid-or-dedicate for Fiber::suspend in destructors, with the proving test
    0035 Security posture proposed unprivileged by default (built); limits, slowloris timeouts, per-IP caps, io_uring off, signed releases (unbuilt)
    0036 Naming proposed (owner's decision) ignis is taken on crates.io; alternatives recorded; rename cost grows after the first public push
    0037 Consolidation to three mechanisms: park, offload, context, one table accepted 2026-09-18 — all four §7 conditions measured (V-46, V-48, V-49, V-51) and cycles 1–3 shipped; status change still needs the sign-off §7 reserves for the main agent seven wait mechanisms → three, target model reached at cycle 3 (V-49); net −1,436 Rust lines, −42 unsafe { (the §1 figure of 1,458/55 was the pre-migration estimate, not the final count); the policy table is the live production policy — flock joined it 2026-09-18 (V-81)
    0038 A lock a fiber can hold across a yield must not live on a file accepted for the rule (V-58); the session-refusal plan (decision 3) was never built and will not be — its premise is refuted (V-80) a blocking flock held across a yield used to deadlock the thread permanently; non-blocking + usleep polling was already fine (Symfony's cache, safe because of park). 2026-09-18: flock itself joined the interposed set instead of locks moving to sockets (V-81, LOCK_NB polling loop, 20 ms ceiling), and separately V-80 found ext/session's files handler never reaches a second flock at all — it is a per-thread singleton, and across threads it serialises and completes exactly like php-fpm — so the boot refusal on session.save_handler=files was dropped as unnecessary, not merely postponed
    0039 Boot-heap snapshot for classic mode (E19) rejected (owner) affordable — 71 µs at the measured 11–12 dirty pages, against a 100 µs budget — but the page rollback is per thread, so it needs budget.fibers = 1 and trades away the in-thread concurrency the runtime exists for; the variant that keeps fibers fails the isolation half of the acceptance
    0040 Temporal: the official PHP SDK on sdk-core accepted workflows are written with temporalio/sdk-php and Ignis is the host — both its transport and its codec are injectable (V-61); the adapter is a portable package under Temporal\Worker\Transport\Core with a two-method port, so it can be offered upstream where the command model it translates actually lives
    0041 A blocking quality gate, and what it costs accepted — its own §7 gate is green on main (all ten jobs of a ci.yml run — seven job definitions, of which e15 is a four-leg matrix — plus image and docs, commit b6c3936 merge(night-2); STATUS.md, BACKLOG R-MAIN-RED) clippy/rustfmt/deny and phpstan/php-cs-fixer/phpunit block a merge from the first commit, so the debt is cleaned in the same body of work rather than deferred; the gate went further than proposed — PHPStan level 8, 0 errors (was 123 at level 6, V-79 addendum, S3-STAN8), undocumented unsafe blocks 101 → 0 including --all-features (V-79 addendum 3), Rust 60 tests / 29.95 % coverage (63 with --all-features, V-78), PHP 209 tests / 36.60 % coverage floored at 31.6 % in CI (V-79 + addenda 1–2); coverage stays reported rather than gated on the Rust side because more than half those lines need a live PHP engine

    Research notes that ADRs rest on live in docs/research/; the numbers in VALIDATION.md.
