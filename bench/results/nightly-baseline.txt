# Baseline for .github/workflows/nightly.yml's hello-world throughput gate (M5-4).
# Format: one bare number per line (req/s, the "Requests/sec" figure from
# `bench/wrk-hello.sh <url> 2 64 10s` against a 1-PHP-thread server), most recent last;
# `#`-prefixed lines are comments.
#
# This file is updated ONLY by the orchestrator recording a VALIDATION.md entry (numbers or it
# didn't happen — DECISIONS, C15). The nightly workflow itself never writes to it.
#
# Starts empty of numbers on purpose: with no numeric line, the nightly job has nothing to gate
# against, so it reports the measured req/s (a "no baseline yet" line, always PASS) instead of
# failing — that reported number is the candidate for the first VALIDATION entry that adds a line
# here. Once a numeric line exists, the job reads the LAST one as the current baseline and fails
# hello_rps only if a run measures below 50% of it.
